# Anjos da Fé

Landing page responsiva criada para apresentar a história, os encontros e a missão do Grupo de Jovens Anjos da Fé.

## Destaques

- Navegação responsiva
- História apresentada em linha do tempo
- Seções sobre atividades, comunidade e participação
- Galeria de imagens
- Layout adaptado para celular e desktop
- HTML semântico e recursos básicos de acessibilidade

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Como visualizar

Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.

## Estrutura

```text
ADF/
├── img/

├── style.css

```
